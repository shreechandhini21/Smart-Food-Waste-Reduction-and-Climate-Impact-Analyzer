SMTP SETUP — GMAIL
===================

1. Create/use a separate Gmail account for the project.
2. Enable Google 2-Step Verification.
3. Create a Google App Password for the project.
4. Copy .env.example to .env.
5. Fill in SMTP_USER, SMTP_PASSWORD and SMTP_FROM.
6. Start Streamlit.
7. Open NGO Matching and use the SMTP connection test.

Gmail settings:
SMTP_HOST=smtp.gmail.com
SMTP_PORT=587
SMTP_USER=yourproject@gmail.com
SMTP_PASSWORD=<16-character Google App Password>
SMTP_FROM=yourproject@gmail.com

RESPONSE_BASE_URL=http://localhost:8501 is only for testing on the same computer.
For a real NGO to click Accept/Decline from their own device, RESPONSE_BASE_URL must be a publicly reachable HTTPS address for the deployed application.

Never put your normal Gmail password in the project code.
Never commit .env to GitHub.
